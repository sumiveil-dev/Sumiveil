# プライバシーポリシー / Privacy Policy

最終更新日: 2026-09-30 / Last updated: 2026-09-30

## 日本語

Sumiveil (以下「本アプリ」) は、個人の開発者 sumiveil-dev が趣味で作っているアプリです。

**集める情報**
- 本アプリも開発者も、利用者の情報を集めません。
- 本アプリはインターネットに接続しません。そのため、次のものはどれも外部に送られません。
  - 入力した文章やファイルの内容
  - 設定
  - 利用状況 (テレメトリ)

**PC に保存するもの**
すべて利用者の PC の中だけに保存されます。
- 設定ファイル
  - 保存先は `%APPDATA%\Sumiveil` (ポータブル版で `sumiveil.toml` を使う場合は、そのファイル) です。
  - 中身は、利用者が登録した語 (除外リスト・独自のルールなど) を含む設定です。
- 診断レポート
  - 作られるのは、利用者が作成を指示したとき、または内部エラーが起きたときだけです。
  - 中身は、バージョン、Windows の情報、設定のオン/オフや件数です。入力した文章、ファイルの内容、登録した語は含みません。
  - 自動では送信されません。
- マスクした結果
  - 利用者が指定した場所にだけ保存されます。
- クリップボード
  - 読み書きするのは、利用者がボタン・ショートカットキー・ホットキーで操作したときだけです。

**第三者への提供**
- 本アプリは情報を集めないため、第三者に提供する情報もありません。

**削除**
- 本アプリをアンインストールすると、プログラムが削除されます。
  - インストーラー版では、アンインストールのときに設定も削除するかを確認します。ポータブル版では、フォルダーごと削除してください (`%APPDATA%\Sumiveil` を使っていた場合は、そのフォルダーも)。

**お問い合わせ**
- GitHub の Issues: https://github.com/sumiveil-dev/Sumiveil/issues
- セキュリティの問題など、公開で書きにくい内容は、リポジトリの「Security」タブから非公開で報告できます。
- 個人の小規模なプロジェクトのため、返答が遅れることがあります。

**改定**
- このポリシーを変更するときは、このページを更新します。

## English

Sumiveil ("the app") is a hobby project by an individual developer, sumiveil-dev.

**Information collected**
- Neither the app nor the developer collects any information about you.
- The app does not connect to the Internet. As a result, none of the following is sent anywhere:
  - the text or file contents you enter
  - your settings
  - usage data (telemetry)

**What is stored on your PC**
Everything is stored only on your PC.
- Settings file
  - It is stored in `%APPDATA%\Sumiveil` (or in `sumiveil.toml` when you use the portable version with that file).
  - It contains your settings, including the words you register (allowlist, custom rules, and so on).
- Diagnostic reports
  - A report is created only when you ask for one, or after an internal error.
  - It contains the version, Windows information, and which settings are on or off and how many items each has. It never includes your text, file contents, or registered words.
  - It is never sent automatically.
- Masked output
  - It is saved only where you choose.
- Clipboard
  - The app reads or writes the clipboard only when you use a button, a keyboard shortcut, or the hotkey.

**Sharing with third parties**
- The app collects no information, so there is nothing to share.

**Deletion**
- Uninstalling the app removes the program.
  - The installer version asks whether to delete your settings as well when you uninstall. For the portable version, delete its folder (and `%APPDATA%\Sumiveil` if it was used).

**Contact**
- GitHub Issues: https://github.com/sumiveil-dev/Sumiveil/issues
- For security problems or anything you would rather not post publicly, use private reporting from the repository's "Security" tab.
- This is a small personal project, so replies may be slow.

**Changes**
- If this policy changes, this page will be updated.
