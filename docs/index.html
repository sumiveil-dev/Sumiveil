Sumiveil (スミベール) は、文章の中の個人情報・機密情報を見つけて、<NAME_1> のような目印に置き換える Windows 用ツールです。ログやメール、チャットの記録を生成 AI や社外に渡す前に使えます。処理はすべて PC の中で完結し、インターネットには一切接続しません。

最新版をダウンロード GitHub で見る

Windows 10 (1809 以降)・Windows 11 (64bit) ／ MIT ライセンス

元のテキスト

To: 株式会社サンプル商事 田中様
TEL 090-1234-5678 ／ tanaka@example1.co.jp
password=NotARealPassword

マスク後

To: <COMPANY_1> <NAME_1>様
TEL <PHONE_1> ／ <EMAIL_1>
password=<PASSWORD_1>

特長

貼り付けるだけで、見つけて、置き換えて、確かめられます。

完全オフライン

入力した文章もファイルも、外部に送信しません。テレメトリ (利用状況の送信) もありません。

67 種類の検出

氏名・住所・電話番号・メールアドレス・マイナンバー・カード番号・IP アドレス・API キー・パスワードなど。カテゴリごとにオン/オフできます。

左右で見比べて確認

元のテキストとマスク後を並べて表示します。見逃しはキーワード辞書に、隠しすぎは許可リストに登録できます。

ファイルもフォルダも

テキスト・ログ・CSV・メール (.eml)・Word / Excel / PowerPoint・PDF などを、フォルダごとまとめて処理できます。

どこからでもホットキー

コピーした文章を、キー操作ひとつでその場でマスクできます。ほかのアプリから離れずに使えます。

コマンドラインにも対応

パイプ入力・JSON 出力・終了コードでの判定に対応し、CI やコミット前の確認に組み込めます。

使い方

3 ステップで終わります。

  1. 貼り付ける文章を貼り付けるか、ファイルをドラッグ & ドロップします。
  2. 確かめる色付きの箇所と検出の一覧を見て、隠すもの・残すものを調整します。
  3. 使う「結果をコピー」で、マスク後の文章を送り先に貼り付けます。
sumiveil -t "田中様 090-1234-5678"
<NAME_1>様 <PHONE_1>

sumiveil report.txt -o report.masked.txt
sumiveil check -r src\   # 見つかったら終了コード 1

自動の検出は完全ではありません。共有する前に、結果を必ず目で確かめてください。

このプロジェクトについて

Sumiveil は、個人の開発者 (sumiveil-dev) による小規模な趣味のプロジェクトです。返答や修正に時間がかかることがあります。開発には、Anthropic の AI コーディング支援ツール Claude Code を使っています。

不具合や要望は GitHub の Issues へお願いします。セキュリティの問題など公開で書きにくい内容は、リポジトリの「Security」タブから非公開で報告できます。Issues には、個人情報や機密情報を含む文章を貼らないでください。

プライバシーポリシー: Sumiveil も開発者も、利用者の情報を集めません。

ライセンス: MIT。使用しているライブラリのライセンスは、配布物の THIRD-PARTY-NOTICES.txt にあります。

English

Sumiveil is a free, open-source Windows tool (GUI and command line) that detects personal and confidential data in text — names, email addresses, phone numbers, addresses, national ID numbers, API keys, passwords, and more — and replaces it with placeholders such as <NAME_1>. Use it to anonymize logs, emails, and chat transcripts before sharing them with AI services or other people.

  • Runs fully offline. Your input is never sent anywhere, and there is no telemetry.
  • 67 detectors you can turn on or off by category, plus your own keywords, allowlist, and regex rules.
  • Side-by-side review, batch processing of folders (text, email, Office files, PDF), a global hotkey, and a CLI for CI checks.
  • The user interface and the guide are mainly in Japanese; the GUI also has an English mode.

Download the latest version from GitHub Releases. Automatic detection is not perfect, so always review the result before sharing it. This is a small hobby project by one person, built with the help of Claude Code. Please report issues on GitHub.
